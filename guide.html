我要上传

不用装软件、不用学 Git，用浏览器就能发布内容

🧭 先说结论：整个网站就是 GitHub 上的一个仓库 Echo-rou/lab-website， 所有内容都以文件形式保存在里面。你用浏览器编辑文件并保存，网站就会在 1~2 分钟后自动更新。 修改仓库需要你的 GitHub 账号被拉进协作成员（找管理员添加一次即可）。

方式一：网页上传（推荐所有人）

登录 GitHub 并打开仓库

用浏览器打开仓库页面：github.com/Echo-rou/lab-website（没账号就先注册一个，然后联系管理员把你加为协作者）。

用模板创建你的分享页面

进入仓库里的 shares/ 文件夹，打开 template.html：

  • 点右上角铅笔 ✏️ 进入编辑模式；
  • 全选复制里面的全部内容；
  • 回到 shares/ 文件夹，点 Add file → Create new file；
  • 文件名按「日期-英文短名」格式起，例如 2026-10-my-esp32-notes.html（文件名建议用英文和数字，避免空格）；
  • 把模板内容粘贴进去，按文件里的中文注释逐项填写。

保存（提交）

填写完成后滚动到页面底部，点绿色的 Commit changes 按钮。默认选项不用改，可以在消息框里写一句「新增：XXX 的电赛复盘」方便日后查找。

把分享加进列表页

打开仓库根目录的 shares.html，点 ✏️ 编辑，在 card-grid 区域最上面复制粘贴一张卡片并改成你的信息：

<div class="card">
  <div class="tags"><span class="tag">比赛经验</span></div>
  <h3><a href="shares/2026-10-my-esp32-notes.html">我的分享标题</a></h3>
  <p class="summary">一两句话的摘要。</p>
  <div class="meta"><span>作者：你的名字</span><span>2026-10-26</span></div>
</div>

同样点 Commit changes 保存。大功告成，1~2 分钟后网站上就能看到你的分享！

怎么上传图片 / 照片？

上传图片文件

在仓库里进入 assets/images/gallery/（相册照片）或 assets/images/（其它图片），点 Add file → Upload files，把图片直接拖进去，然后 Commit changes。

在页面里引用

相册页 gallery.html：复制一张 g-item 卡片，把 src 换成你的文件名；
分享正文里插图：用 <img src="../assets/images/你的图片.jpg" alt="说明">（注意分享页在 shares 文件夹里，路径前要加 ../）。

方式二：本地 Git（会用 Git 的同学）

克隆 → 修改 → 推送

git clone https://github.com/Echo-rou/lab-website.git
cd lab-website
# ...照方式一的说明添加你的分享文件 ...
git add .
git commit -m "新增：XXX 的分享"
git push

推送后网站同样会自动更新。

注意事项

🗂 文件命名

分享页面和图片文件名用英文、数字和连字符，如 2026-10-esp32-notes.html；标题在文件内容里写中文即可。

📦 图片大小

单张照片建议压缩到 1MB 以内（微信截图/手机原图可先压缩），单文件超过 25MB 网页上传会失败。

🔒 内容安全

仓库是公开的：不要上传涉密内容、他人隐私（证件、成绩单）和有版权争议的资料；引用别人的文章要注明出处。

🆘 改坏了怎么办

别慌。GitHub 会保存每次修改历史，联系管理员就能恢复到任意旧版本，不会真的弄丢。
